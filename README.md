# 📚 Book Management System (CRUD App)

A simple and user-friendly **Book Management System** that allows users to **add, view, edit, and delete books**.  
This project demonstrates core **CRUD operations** with a clean UI and smooth navigation.

## 🚀 Features

- ➕ Add New Book
- 📖 View All Books
- ✏️ Edit Book Name
- ❌ Delete Book
- 🔁 Smooth page navigation
- 🌙 Dark theme UI

---

## 🖥️ Screens / Pages

### ➕ Add Book Page
- Enter book name
- Add book button
- View all books option

### 📖 All Books Page
- Displays all books
- Edit & Remove buttons
- Add new book option

### ✏️ Edit Book Page
- Update existing book name
- Save changes
- Back to all books option
